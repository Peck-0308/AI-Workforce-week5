# Observations – Use Case 3

## 1. Prompts That Worked Well
The following prompts produced clear and useful responses:
- "Explain the topic in simple terms"
- "Give an example of how this works"
- "How can a beginner get started?"

These prompts helped the agent provide structured and understandable answers.

## 2. Accurate vs Inaccurate Responses
- Accurate responses:
  The agent gave clear explanations and relevant information related to the topic.

- Inaccurate responses:
  Some responses were slightly vague or lacked detail, especially when prompts were not specific enough.

## 3. Agent Behavior
The agent mostly stayed within its defined purpose. It responded based on the instructions given and did not go off-topic in most cases.

## 4. Areas for Improvement
- Improve prompt clarity to get more precise answers
- Add more detailed instructions in the agent configuration
- Ensure responses include examples where necessary
- Reduce vague or generic responses

## 5. Overall Experience
The process of creating and testing the agent was insightful. It showed how important clear instructions and well-structured prompts are in getting accurate and helpful responses from AI systems.
